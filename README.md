# ATP Accountants — homepage redesign concept

Homepage redesign concept for [ATP Accountants](https://atp-accountants.co.uk/) (Amersham), by DigitalSEOs.

- Single-page static site: `index.html` + `assets/`
- GSAP 3 + ScrollTrigger (loaded from cdnjs): hero line reveal, scroll-velocity marquee, word-fill statement, pinned horizontal roadmap (stacks on mobile), parallax images, counters
- Fully responsive; respects `prefers-reduced-motion`

## Preview
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Photos are free stock placeholders; the founder card is a placeholder until a real headshot is supplied.
